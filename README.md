# Resoluções - Introdução a Estruturas de Dados em C

> **Status:** Em desenvolvimento contínuo (Avanço progressivo conforme o cronograma de estudos algorítmicos).

Repositório destinado ao armazenamento das resoluções dos exercícios práticos do livro "Introdução a Estruturas de Dados — com técnicas de programação em C" (2ª ed.).

## Objetivo
O projeto atua como um laboratório de base algorítmica. O foco primário é a implementação manual e o domínio do gerenciamento de memória em C (alocação dinâmica e ponteiros), construindo os fundamentos necessários para a compreensão profunda de estruturas complexas antes de sua utilização em linguagens de mais alto nível.

## Estrutura do Repositório e Progressão
Os exercícios foram agrupados em blocos lógicos de evolução técnica:

### Fase 1: Fundamentos da Linguagem e Memória (Capítulos 1 a 12)
- [x] Lógica de fluxo, operadores e tipagem primitiva.
- [ ] Manipulação de ponteiros, funções e passagem por referência.
- [ ] Alocação dinâmica de memória (malloc, free) e Tipos Abstratos de Dados (TAD).
- [ ] Manipulação de arquivos e algoritmos fundamentais de busca e ordenação.

### Fase 2: Estruturas de Dados Lineares (Capítulos 13 a 15)
- [ ] Implementação de vetores dinâmicos.
- [ ] Construção manual de listas encadeadas (simples, duplas e circulares).
- [ ] Modelagem de Pilhas (LIFO) e Filas (FIFO).

### Fase 3: Estruturas Não-Lineares e Grafos (Capítulos 16 a 22)
- [ ] Árvores e algoritmos de percurso.
- [ ] Tabelas de Dispersão (Hashing) e tratamento de colisões.
- [ ] Grafos, Listas de Prioridade e estruturas Union-Find.
